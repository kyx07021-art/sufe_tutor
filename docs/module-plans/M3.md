# M3 C1 关系管理 · 基元拆解清单（2026-08-22）

> 拆解 agent a04b10e5 产出。11 条基元。模块核心 = 虚线弯曲算法（M3-04）与流向动效（M3-07）。

## 模块级决策（已定案）
1. 数据源 I-15（v2-ready AI-7 考古，响应形状实证：{relations:[{conversationId,status,other:{...},last,signing|null}]}）。
2. **合同边本轮不渲染（主会话定案）**：合同前端组件本轮不写（用户定案），M3-01 边模型只建会话边、忽略 signing；I-15 的 signing 字段保留传给 M4（「有合同则结束会话灰掉」判断用）。
3. 会话状态映射：active=会话中 / closed=已结束（与 chatClosedNow 同源口径）。
4. 教师 id 规则：关系图头像下 id 显示教师名（B 端）。
5. z-order token：底板格点 0 / 虚线 1 / 头像 2 / 关系卡 3（M3-02 定值，模块内单源）。
6. 同心圆半径 R 由容器派生，resize 重算。
7. JS 只切类、动画全 CSS（流向走 SVG dashoffset）、reduced-motion 降级但虚线/卡仍可见。
