# ADR 0004 — 新前端组件架构契约设计

- 状态：**已接受**（2026-08-21，用户授权主会话自主定案）
- 前置：ADR 0002（Vue 3 + Vite）、ADR 0003（认证/路由横切面）、需求 T 解耦度报告
- 范围：新前端（经世知途·信息门户平台）组件架构契约——组件表达、设计 token 单源、动效契约、接口帽模式。**每个 agent 开工前先读**（AG-5 PROJECT.md 全文引用本契约）。

## 1. 组件表达范式

**组合优先于类继承**（Vue 3 SFC + `<slot>` + composable）。"base 元素 + 个性化接口" = 单实现 + 变体参数（prop 驱动），非复制多组件。

### 1.1 组件通用形态

```
src/components/
  ui/         基础原子（Button/Input/Select/Badge/Tag…）
  layout/     布局原子（Shell/Sidebar/Modal/Toast…）
  domain/     业务组件（TeacherCard/DemandCard/ConversationRow…）
```

每个组件 = 一个 `.vue` 文件（模板 + 逻辑 + scoped 样式一体）——**一个基元一个文件**，props 进 / emit 出接口清晰（数千基元并行开发的前提）。

### 1.2 按钮变体契约（用户蓝图钉死）

单个 `UiButton.vue`，`variant` prop 驱动 A/A1/B/B1（B2/C/C1 按需扩展，同模式）：

| variant | 常态 | 悬停 | 点击 | 附加 |
|---|---|---|---|---|
| **A** | 底色填充 + 1px 黑细边框，胶囊型（两端半圆 + 中间直线） | 从鼠标位置圆形扩散成 15 度灰 `--gray-15`（~100ms） | 从鼠标位置呼出深一色黑圆形扩散填满按钮 → 填满后全体均匀变淡回单灰（~700ms） | 固定宽度不随内容变；取消悬停均匀变回原色 |
| **A1** | = A | = A | = A | 右侧向右 SVG 箭头（离文本约一个全角空格；箭头+文本整体居中；聚焦/悬停箭头小幅右移；移回；点击无额外反应） |
| **B** | 无填充无边框，仅黑字 | = A 的胶囊判定/聚焦/点击效果（淡灰圆形扩散） | = A 点击效果 | 无框无底 |
| **B1** | = A1 的无填充无边框黑字 | = B 悬停 | = B 点击 | 箭头同 A1 |

- 文本/SVG 悬停平滑变 60 度灰 `--gray-60`（200ms，移开回黑 `rgb(26,26,26)`）；键盘聚焦慢扩散 400ms（`--btn-dur-focus`）。
- 动效时长 token 见 §3；涟漪坐标契约 = **局部坐标**（组件内 rect 换算，键盘触发用组件中心）。

### 1.3 组件接口纪律

- props 白名单 + 默认值；emit 命名 `update:*` / 业务语义名。
- **零内联事件/样式属性**（Vue 模板 `@click` 是框架绑定非 HTML 内联——仍禁 `style="..."` 属性与 `v-html` 注入）；scoped 样式经构建期抽离外部 CSS（ADR 0002 CSP 约束）。
- 组件只切类（开闭/聚焦/悬停），零运行时内联 style；动效全在 CSS 呈现层。

## 2. 设计 token 单源

`src/styles/tokens.css` 定义 `:root` CSS 变量（单源，组件消费变量名，禁裸值）。暗色模式经 `html[data-theme="dark"]` 翻转同一变量名。

### 2.1 色阶（8:1:1 配比）

| token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg-base` | 8 分白（#fff 系） | 8 分泛紫深灰 | 页面底色 |
| `--ink-strong` | 1 分灰黑 | 1 分灰白 | 主文字 |
| `--brand` | 亮款品牌紫 | 暗款品牌紫 | 品牌点缀（1 分） |
| `--gray-15` | #d9d9d9 | 暗色对应灰 | 悬停填充 |
| `--gray-60` | #666666 | 暗色对应灰 | 次级文字/悬停文字 |

灰度阶（白→黑）与紫阶（亮→暗）作为一组 token 表落位，组件不得跨 token 直用 hex。

### 2.2 几何与布局 token

| 类 | token 例 | 约定 |
|---|---|---|
| 线宽 | `--border-w` | 细线统一 1px；强调 2px |
| 圆角 | `--radius-sm/md/lg` | 图片圆角裁切/卡片/胶囊（半圆=高度/2 由组件算） |
| 间距 | `--space-1..8` | 8 基准间距系统；组件之间留空（紧贴是缺陷，规则 P9） |
| 占宽百分比布局 | `--col-golden` 等 | 镜像双分区（右图 1/3 / 左字区动态定宽）用百分比 + `minmax` 栅格，不写死 px |
| 屏边空区 | `--page-inset` | 左右各 100px 空区（组件不得超出、可紧贴内边缘）；窄屏收缩 |

### 2.3 动效时长 token

| token | 值 | 用途 |
|---|---|---|
| `--btn-dur-in` | 100ms | 悬停填充扩散 |
| `--btn-dur-color` | 200ms | 文字/SVG 颜色过渡 |
| `--btn-dur-focus` | 400ms | 键盘聚焦扩散 |
| `--btn-dur-click` | 700ms | 点击涟漪 |
| `--dur-fade` / `--dur-float` | 300ms / 500ms | 浮入淡入 / 滚动进出（上浮 24px / 下浮 -24px） |

## 3. 动效契约

1. **JS 只切类**：开闭/聚焦/悬停状态全由 JS 切换 class（如 `.is-open`/`.is-active`），零内联 style 写入。
2. **CSS 呈现**：动画/过渡全在 CSS（transition / @keyframes / Vue `<Transition>` 钩子类）。
3. **涟漪 = CSS 变量数据通道**：扩散圆用 `--ripple-x/--ripple-y` 变量 + `transform: scale()` keyframes（CSSOM 通道，CSP 兼容，ADR 0002）。
4. **reduced-motion**：`@media (prefers-reduced-motion: reduce)` 下退化为瞬时切换（**页面核心设计动效除外**——如滚动浮入，用户可感知开关：默认遵循 reduced，项目设置可显式覆盖）。
5. **可滚动组件**：浮入+淡入 / 浮出+淡出轻盈感；图片边缘随坐标缩放（不进视口边缘不缩放），渐变遮罩与背景同色。

## 4. 接口帽模式（未就绪接口）

新前端从零打造期间，服务端标准业务接口（T-5 清单）分三态：

| 态 | 标记 | 行为 |
|---|---|---|
| 已接入 | 正常实现 | 组件真实调用 `api()` 单点 |
| 接口帽（dummy） | 组件 prop/数据位占位 + `data-cap="<接口名>"` 标记 | 渲染占位/骨架，点击 toast「功能开发中」；不假请求 |
| 未定义 | 蓝图页面暂缓 | 不在路由表注册 |

纪律：**接口帽必须显式标记**（禁止"看起来能用其实空"的死 UI）；帽摘除 = 独立基元（替换占位 + 接入真实接口 + 审计）。

## 5. 与既有架构契约的关系

- **契约 6 精神延续**：源码零内联事件/样式属性、零运行时 `<style>` 注入、零中文文案（Vue 模板改由框架绑定承担内联事件面；`style="..."` 属性与 `v-html` 仍禁）。
- **设计 token 单源**（规则 P4 精神）：数值/色值/时长只进 tokens.css，组件零裸值。
- **组件留空/提亮面**（规则 P9）：组件间距用 `--space-*`；压暗灰底上的玻璃组件用提亮面 token。
- **动效解耦**（规则 P7）：开闭状态管理与动画彻底解耦（JS 只切类）。
- **接口帽**（规则 F4 反例）：空容器/零 handler/零消费 = 死 UI，接口帽显式标记防之。
