## 1. 网站目的

**经世知途·信息门户平台**（家教信息对接）：学生发布家教需求、教师入驻并展示档案/接单、双方经会话沟通、签约并签署电子合同完成交付。平台提供评价、奖学金荣誉、帖子资源广场、通知公告与投诉反馈。

- 学生客户端：找教师 / 发需求 / 管关系。
- 教师客户端：找需求 / 完善档案（含学信网核验）/ 资料广场。
- 管理端：用户/需求/评价/内容/合同/奖学金/认证/帖子/反馈/邀请码/流量 11 模块。

## 2. 后端架构简介

- **运行时**：Cloudflare Workers + D1（SQLite）+ Pages 静态托管。前后端同仓库，前端经标准业务接口 `/api/*` 通信。
- **架构**：`core/` 咽喉（auth/security/session/crypto/notify/log…）+ `domains/<域>/{schema,repo,api}` 三件套 + 声明式路由表。
- **共享单源**：`src/shared/{config,enums,codes,region-data}.js`（限额/枚举/文案码/省份政策）前后端同源。
- **严格 CSP**：`script-src 'self'; style-src-elem 'self'; style-src-attr 'none'`——零内联脚本/样式（新前端 Vite 产物天然满足，禁 CSS-in-JS）。
- **身份**：X-Auth-Token 请求头 + `/api/auth/me` 恢复 + 401 兜底；危险操作 capToken 二次认证。
- **接口清单真源**：`docs/frontend-decoupling.md`（112 标准业务接口，16 组业务能力）；**接口映射表**：`docs/interface-mapping.md`（页面 × 接口 × 接口帽）。

## 3. 前端样式设计（设计 token 单源）

**总风格**：纯白、扁平、极简。8 分白 / 1 分灰黑 / 1 分亮色款品牌紫（暗色反转为 8 分泛紫深灰 / 1 分灰白 / 1 分暗色款品牌紫）。少边框线、文字直接坐模块底色；下拉栏 = 文字 + 向下 v 形无外框；悬停呼出灰色气泡衬底。动效柔和、可滚动组件浮入+淡入。

### 3.1 色阶 token

| token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg-base` | 白系 | 泛紫深灰 | 页面底色 |
| `--ink-strong` | 灰黑 | 灰白 | 主文字 |
| `--brand` | 亮品牌紫 | 暗品牌紫 | 品牌点缀 |
| `--gray-15` | #d9d9d9 | 暗灰 | 悬停填充 |
| `--gray-60` | #666666 | 亮灰 | 次级/悬停文字 |

### 3.2 几何/布局/动效 token

- 线宽 `--border-w`（1px/2px）；圆角 `--radius-sm/md/lg`（图片圆角裁切）；间距 `--space-1..8`（8 基准，组件留空=规则 P9）；占宽百分比 `--col-*`（镜像双分区用 `minmax` 栅格）；屏边空区 `--page-inset`（左右 100px，组件不得超出）。
- 动效时长：`--btn-dur-in` 100ms / `--btn-dur-color` 200ms / `--btn-dur-focus` 400ms / `--btn-dur-click` 700ms / `--dur-fade` 300ms / `--dur-float` 500ms。
- 全表见 ADR 0004 §2；组件消费变量名，禁裸值。

## 4. 组件架构契约（摘要，全文 ADR 0004）

- **Vue 3 SFC**：一个基元一个 `.vue` 文件（模板+逻辑+scoped 样式一体），props 进 / emit 出。
- **按钮变体 A/A1/B/B1**：单 `UiButton.vue` + `variant` prop（A=胶囊填充+黑细边框、A1=+箭头、B/B1=无填充黑字同动效）；涟漪 = CSS 变量数据通道 + transform 扩散；动效时长走 token。
- **接口纪律**：零内联 style 属性/零 v-html 注入/零运行时 `<style>`；JS 只切类，动效全在 CSS；组件间距用 `--space-*`；玻璃组件用提亮面 token。
- **接口帽**：未就绪接口占位 + `data-cap="<接口名>"` 标记（禁"看起来能用其实空"），帽摘除=独立基元。

```

AB 共用：C0 LOGO；C1 关系管理→C1.1 关系卡片；C2 会话页（C2.1 普通气泡/C2.2 特殊气泡/C2.3 会话选择栏/C2.4 发起签约/C2.5 起草合同/C2.6 更多侧边栏）；C3 通知侧边栏；C4 更多侧边栏（C4.1 设置/C4.2 关于/C4.3 反馈）
认证视图：登录（密码/验证码）/注册（学生/教师+邀请码）

```

- **路由**：Vue Router，**memory history**（纯状态，零 URL 竞态）+ 记忆上次页；角色门禁走 `beforeEach` 守卫。
- **认证**：X-Auth-Token 注入 api() 单点 → `/api/auth/me` 恢复 → 401 单点兜底清态回登录；capToken 二次认证逐次新签发。
