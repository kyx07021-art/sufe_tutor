# 运营建议 · 2026-08-01

> 基于同行业务模式研究 + 平台现状分析。目标：找准差异化空间，提出可落地（优先纯前端/SQL 能做的）优化。
> 平台现状：零佣金撮合 + 需求大厅/教师广场 + 会话/合同/评价/资料共享 + 管理员端，身份凭令牌，联系方式签约后展示。

---

## 一、同行格局与平台定位

### 1.1 行业现状（2026）

- **主流模式**：信息中介费制——向老师收"信息费"（按周课 60–150% / 按月 15–20% / 线上 ×1.3）。预付 + 退费难 + 中介纠纷隐身是行业三痛点。
- **合规红线**：《校外培训行政处罚暂行办法》(2023)——平台若"以撮合为名行培训之实"（统一定价、抽成管理、组织排课）可能被认定变相培训机构。**纯撮合、不碰结算**是安全区。
- **AI 冲击**：免费 AI 讲题让"标准知识传授"贬值，但**陪伴、督学、定制适配、家长沟通**是 AI 替代不了的服务溢价。
- **信任真空**：家长对师资不可验证 + 中介信息不透明 → "试课前完全不可知"。

### 1.2 我们的差异化空间

| 维度 | 行业现状 | 我们的优势 | 可打的牌 |
|---|---|---|---|
| 收费 | 高额信息费 | 零佣金撮合 | "永不提前收费"信任锚点 |
| 师资 | 不可验证/履历造假 | 上财在校生背书 | 学籍认证徽章 + 专业/成绩公示 |
| 匹配 | 微信群抢单 | 结构化需求/教师画像 | 双向匹配 + 匹配度显示 |
| 信任 | 无合同/无担保 | 已有电子合同 + 评价 | 试课担保 + 一课一消（方向） |
| 合规 | 灰色地带 | 纯撮合定位 | "不办学"声明 + 学生家长直连 |

**核心主张**：做"家教界的直聘"——家长直接找到真实可验证的上财学生，无中介、无预付、无信息差。

## 二、平台主要问题与解决方案（按优先级）

### P1 教师注册门控 vs 增长（已在 0.18.22 开启邀请码门控）
- **现状**：教师注册需邀请码（F-05 安全整改），但增长受限。
- **方案**：管理员侧边栏已能"生成邀请码"。补充：学生推荐教师入驻得积分/优先匹配权；教师分享邀请码绑定推荐关系。低成本（纯 SQL 记录推荐人）。

### P2 联系方式"签约后展示"的双刃剑
- **现状**：联系方式签约后才展示（合规 + 防骚扰），但**会阻断前期沟通**——家长/老师需要先聊起来才能决定是否签约。
- **方案**：分层信任——(a) 平台内站内信（已有会话）承担前期沟通；(b) 意向确认后、签约前开放**虚拟号**或"站内联系方式"（隐藏真实手机）。最简实现：签约前双方仅能站内聊（现状），签约时平台生成一次性联系码。

### P3 匹配效率：从"抢单"到"撮合"
- **现状**：需求广场教师浏览 + 提交意向（接单制）。
- **方案**：
  1. 需求卡片加"期望开课时间 + 可试听时段"字段（纯 SQL）
  2. 教师意向带"报价 + 档期模板"勾选，家长一键接受即成交（减少来回）
  3. 双向画像：家长（年级/科目/性格标签/距离/预算）+ 教师（专业/风格/时段）→ 列表显示"匹配度 N%" + 推荐理由（"距你 3km / 擅长引导内向孩子"）

### P4 信任与履约保障（中期）
- **现状**：电子合同 + 评价（学生评教师）。
- **方案**：
  1. **学籍认证**：上财校园邮箱/学生证上传 → "已认证"徽章（0.19 后教师档案已有 credential_image 字段，做审核流即可）
  2. **双向评价**：教师也能评家长（守时/配合度），防放鸽子
  3. **试课担保**：首课不满意免课酬/免费换人（退款状态逻辑，纯后端）
  4. **一课一消**：家长确认后放款（需第三方托管，中成本，方向）

### P5 新用户冷启动
- **现状**：落地页 + 登录注册，无新手指引。
- **方案**：需求大厅/教师广场加"示例卡片"（3 条模拟数据引导理解流程）；注册后引导弹窗（"发布需求"或"完善档案"）。

## 三、新业务方向 brainstorm

### B1 沟通链简化（核心）
- 需求 → 意向 → 会话 → 合同 → 签约 → 首课，当前链路上会话环节是必要的（建立信任），但**重复沟通**可压缩：
  - 意向请求带结构化信息（报价/时段/方案摘要），家长接受即建立会话且会话内预置需求摘要（已有）
  - 合同起草表单从会话上下文自动预填（已部分实现）
- **建议**：每个环节的"下一步"按钮置顶 + 状态机进度条，减少用户思考。

### B2 精确匹配客群
- **家长侧**：按区域（上海区县）+ 年级 + 目标（提分/补差/竞赛/陪伴）细分需求标签 → 教师按擅长匹配
- **教师侧**：按专业对口（数学系→数学）+ 可排时段 + 通勤半径筛选需求
- **算法初筛**：SQL 可做——科目交集 + 区县匹配 + 预算区间交叉，按匹配度排序（比"最新发布"排序转化率高）

### B3 校园社区化
- 现有"资料共享"（帖子广场）是起点。扩展：
  - **学长学姐经验帖**：高考/考研/选课攻略（带流量，低门槛）
  - **拼课**：同小区/同校低年级拼单（一拖二），摊薄价格（需防合规风险——平台只撮合不组织）
  - **家长社区**：家长分享孩子学习问题，教师专业回答（内容营销）

### B4 服务分层（远期）
- 免费撮合（现状）→ 增值：托管支付（一课一消）、保险保障（授课意外险）、教师培训/评级（平台认证优质教师）

## 四、现有模块优化建议（低成本优先）

### M1 需求大厅（教师侧首页）
- 缺筛选：加科目/年级/区县/预算筛选（filter-panel 已有 UI 基础）
- 缺排序：按发布时间/匹配度/预算高低
- 缺收藏：需求收藏（后续好找）

### M2 教师广场（学生侧）
- 教师卡片信息密度低：突出专业/年级/报价/评价数，加"匹配我的需求"标记（已有 matched 概念）
- 加排序：按评价/价格/最近活跃

### M3 我的会话
- 会话列表缺"未读红点"外的信息：最后消息预览已有，加"对方在线状态"（活跃时间）
- 会话内快捷操作：起草合同按钮已有，加"查看对方档案"入口

### M4 资料共享
- 帖子缺分类/标签体系（section 字段预留了但未用）：启用分区（真题/经验/笔记）
- 帖子缺搜索高亮 + 点赞数排序（已有 hot 排序）

### M5 管理员端
- 统计页缺趋势图（纯 SQL 出近 7 天注册/需求/签约曲线）
- 缺教师审核流（0.19 的学籍认证需要）

---

## 五、最值得先做的三件事（建议落地顺序）

1. **需求卡片结构化 + 匹配度显示**（P3 + B2）：纯 SQL + 前端排序，改动小、直接提升匹配效率——这是平台从"信息列表"到"撮合引擎"的关键一步。
2. **学籍认证徽章 + 教师审核流**（P4.1）：已有 credential_image 字段，补审核路由 + 徽章展示，建立"真实可验证"信任锚点（核心差异化）。
3. **新用户引导 + 示例卡片**（P5）：落地页和空态加引导，降低首次使用门槛。

## 六、风险与合规提示

- 保持"纯撮合、不结算、不组织培训"定位（合规红线）
- 联系方式展示严格遵守"签约后"策略（已实现），防骚扰（未成年人保护）
- 电子合同保留（法律依据），平台只存证不居间
- 免费 AI 冲击：宣传定位转向"陪伴/督学/定制"，而非"提分承诺"
