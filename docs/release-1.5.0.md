# v1.5.0 发布说明与运维清单

## 用户可见变化

- 正式上线安全收口：学信网核验改为人工核验队列，取消内测模拟通道；内容审核在服务不可用时不再静默放行。
- 管理端新增运行观测面板：24 小时请求量、服务端异常、慢请求、限流命中、平均耗时、高频接口与状态码分布。
- 全站视觉统一：玻璃卡片层次、间距留白、按钮层级、教师卡/需求卡/设置页重点优化；小字对比度达到 WCAG AA。
- 全站文案重写：登录注册、空状态、错误提示、系统通知、管理端说明去除过时与模板腔。

## 运维清单（发布前，仅用户可完成）

1. 按 `docs/secrets-plan.md` 上传全部 Worker Secrets。
2. 确认 `ADMIN_DEFAULT_PASSWORD` 为全新强口令。
3. 部署后 `curl https://sufe-tutor.pages.dev/api/health` 返回 `status: ok`。
4. 执行 `SUFE_ADMIN_PASS='<新口令>' bash scripts/reencrypt-production.sh`，确认 `unreadable: 0`。
5. 删除 `*_OLD` 密钥后重新发布。
6. 管理员登录拉取反馈单巡检。
