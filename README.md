
业务范围包含：
- 信息登记
- 匹配需求
- 双方沟通
- 见证签约
业务范围不含：
- 报酬收发
- 维护师生关系
- 纠纷调解
- 服务质保

### 三级信息管控机制：
- 一级（公开）：学科、年级、地区、时段、报价区间、自我介绍
- 二级（双向匹配后可见）：真实姓名、学校、头像、精确到街道/小区的双方住址、学信网信息（？）
- 三级（签约后可见）：手机号、精确住址、微信

### 签约流程：
学生提交需求
教师提交接单意向
家长按需发起平台内沟通
任意一方起草接单具体信息
双方确认签约，转点对点交流

### 数据安全：
信息储存在境内服务器
敏感字段加密，密钥隔离存储
全额信息带时间戳加密留档（用户信息、匹配记录、聊天记录、签约记录、管理员访问敏感信息记录）

### 公测架构：
阿里云轻量化服务器（低质38/年 ）+阿里云注册域名（60/年），服务器存储全部业务信息：
敏感字段存到同机 PostgreSQL/MySQL
密钥放服务器环境变量（不进代码）
合同 PDF 文件初期直接存服务器磁盘，后期用户多了再迁到腾讯云 COS/阿里云 OSS
用户数据初期存服务器磁盘，后期迁到 COS/OSS + CDN 加速

### 内测架构：
cf境外全托管
上线后进行公安备案
不收集敏感数据（家庭精确住址），写明确独立提示信息，让用户同意手机号信息出境
秘钥放worker secrets里边
同步提交ICP备案

### 登录注册：
所有用户SMS验证码注册，学生注册需家长验证码确认
（内测阶段）教师注册需邀请码

### 平台内签约：（可找开源电子协议直接用）
双方确认时间、单价等基础信息，平台自动生成合同
身份专有性：注册需SMS验证码+合同确认号码已实名验证
确保本人操作：签约需sms验证码确认
防篡改：合同和签名记录用时间戳+哈希认证，哈希值独立存储
